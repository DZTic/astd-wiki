| Version | Supportée |

## Signalement d'une vulnérabilité

La sécurité de ce projet et de ses utilisateurs est prise très au sérieux.

Si vous découvrez une faille de sécurité ou une vulnérabilité potentielle :

1. **Ne créez pas d'issue publique** afin d'éviter toute exploitation malveillante avant résolution.
2. Signalez la vulnérabilité de manière confidentielle via le bouton **"Report a vulnerability"** dans l'onglet **Security** du dépôt GitHub.
3. Veuillez inclure dans votre signalement :
   - Une description détaillée de la vulnérabilité.
   - Les étapes pour reproduire le problème ou une preuve de concept (PoC).
   - L'impact potentiel estimé.

Nous nous engageons à accuser réception dans les plus brefs délais et à déployer un correctif rapidement.
